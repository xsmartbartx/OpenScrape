Schedule (optional)

Five numeric fields: minute, hour, day of month, month, weekday (0 = Sunday). Example runs at 09:00 Monday–Friday. The server must be running.

Pagination (optional)

Use {page} where the page number belongs. Without a template, the start URL is fetched once.

Repeated records (optional)

Leave empty to extract one record from the whole page. Add a simple tag, .class, or #id selector to repeat the fields below for each match.
